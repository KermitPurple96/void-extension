Sync Bridge — share traffic between containers

      

        The sync bridge relays HTTP history between all Void instances in real-time.
        Start it once, then open the Logger tab in each instance — sync connects automatically.
      

      

        

          1
          

            
Install dependency (once)

            cd C:\tmp\void-extension && npm install ws
          

        

        

          2
          

            
Start the sync bridge

            node void-sync-server.js
          

        

        

          3
          

            
Open Logger tab

            Sync connects automatically. Green dot = connected. All containers share traffic.

Match & Replace

        
Automatically modify requests and responses. Rules apply to intercepted traffic (debugger) and Repeater.

        

        
      


      
      

        
Auto Headers

        
Headers injected into every outgoing request (intercepted + Repeater). One per line: Name: Value

        

          
        

        
      


      
      

        
Upstream Proxy

        
Route Repeater requests through a proxy. Does not affect browser traffic (use system/extension proxy for that).

        

          
        

        

          
          
          
          
        

        

          
          
        

      


      
      

        
Scope

        
Limit History capture & Match/Replace to matching URLs. One pattern per line. Supports * wildcard. Leave empty = capture all.
